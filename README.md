# archer.power

Omarchy power panel with a battery tooltip showing time remaining (or to full) and wattage.

A modified copy of the built-in `omarchy.power` plugin from [Omarchy](https://github.com/basecamp/omarchy) (MIT). It replaces the stock plugin when enabled; `omarchy plugin remove archer.power` restores it.

Install: `omarchy plugin add <this repo's git URL> --enable`

Personal config, shared as-is: no support or compatibility promises.
